# 海龟汤公平性审计表

## 核心检查

| 项目 | 合格标准 | 常见失败 |
|---|---|---|
| 唯一性 | 汤面与常识结合后只有一个完整解 | 多个汤底都能解释全部线索 |
| 可推导性 | 关键跳跃有至少两条相互独立的线索支撑 | 靠作者说“其实……” |
| 语义诚实 | 汤面句子在通常语境下不撒谎 | 偷换“进入”“看见”“房间”等词义 |
| 物理可行 | 移动、视线、声音、时间符合场景条件 | 依赖未说明的密道或魔法 |
| 动机闭合 | 诡计能解释人物为何这样做 | 只为制造反转而行动 |
| 问答稳定 | 常见问题可预先归类并一致回答 | 主持时临时补设定 |

## 替代解压力测试

至少尝试以下方向：

1. 普通谋杀或事故；
2. 时间记录错误或时区错位；
3. 叙述者不可靠或指代错位；
4. 空间边界、镜像、遮挡或路线误读；
5. 身份替换、伪装或尸体误认。

如果其中一个方向能同样解释全部线索，应增加区分性线索或重写汤底。

## 提示阶梯模板

- 一级：指出最反常的一个词或时间点。
- 二级：指出玩家默认的时间线、空间模型或观察者可能错了。
- 三级：确认主诡计类别，但不说具体机关。
- 四级：给出还原顺序，保留最后一步让玩家完成。
