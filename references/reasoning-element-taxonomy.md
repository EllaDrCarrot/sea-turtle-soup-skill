# 海龟汤推理元素与设计分类

这套分类用于出题、审题、语料标注与结构学习。它是多轴坐标，不是互斥题型表：一道题可同时属于“变格现实性 + 时间主机制 + 科技实现层 + 闭环结构 + 悲剧主题”，但每个标签必须说明它在推理中的功能。

## 一、现实性：答案依赖哪一类世界规则

- `classic` 本格：只依赖现实中的物理、心理、社会、语言与犯罪手段。
- `speculative` 架空规则：存在现实中没有但可精确定义、可稳定推演的科技或世界规则。
- `supernatural` 超自然：灵魂、鬼怪、神灵、诅咒、异能等在题内真实成立。
- `hybrid` 混合：现实案件机制与架空或超自然机制都承担必要推理功能。
- `ambiguous` 两解并立：题目有意保留两个均受线索支持的本格/变格解释；这是一种设计结论，不是材料不足。
- `uncertain` 待确认：现有材料不足，暂不判断。

本格/变格描述的是规则来源，不描述难度。超自然规则一旦采用，也要像物理定律一样说明触发条件、作用对象、边界、代价与可观察后果。

## 二、核心推理机制：玩家必须重构什么

### 1. 时间

- 顺序错位：倒叙、插叙、事件顺序与叙述顺序不同。
- 时间口径：发生、记录、发送、接收、发现、感知时间被混同。
- 时长与频率：年龄、周期、班次、重复次数或等待时长被误判。
- 非同步：时区、钟表、不同观察者或局部区域时间不一致。
- 循环与重置：信息、物体、人物或世界状态跨轮次保留。
- 时间旅行与分支：穿越、祖父悖论、自洽闭环、平行分支或时间反演。

### 2. 空间与物理

- 视线与遮挡：镜面、影子、摄像头、盲区、声音方向或可见范围。
- 边界与容器：房间、建筑、车辆、身体、画面或“里面/外面”的边界错认。
- 尺度与坐标：大小、远近、上下、楼层、地图方向或参照系变化。
- 路线与拓扑：入口出口、单向路径、旋转、折叠、连通关系或不可能路线。
- 密室与不可能犯罪：出入条件、封闭时点、机关、物理痕迹与作案窗口。
- 物理过程：温度、压力、浮力、燃烧、腐败、药理、声光传播或机械延迟。

### 3. 身份与存在状态

- 人物错认：替身、双胞胎、伪装、年龄阶段、称谓或多人共用身份。
- 物种/对象错认：叙述对象并非人，或把模型、图像、尸体、器官、程序当作真人。
- 生死与状态错认：死亡时间、假死、脑死亡、失踪、出生或“活着”的口径。
- 身体与意识分离：换身、克隆、人格复制、意识上传、附身、魂穿或夺舍。
- 社会身份错位：职业、亲属、法律身份、游戏角色、账号与现实主体不一致。

### 4. 感知、记忆与认知

- 感官限制：失明、失聪、色觉、痛觉、语言识别或非人类感官差异。
- 注意与框架：选择性注意、习惯盲区、恐惧预期、文化预设或错误常识模型。
- 梦境与幻觉：梦、药物、疾病、催眠、VR 或精神症状改变所见，但需留下可区分线索。
- 记忆机制：失忆、虚假记忆、记忆移植、重复覆盖或不同人格共享记忆。
- 心理与人格：解离、妄想、人格分裂、创伤反应或自我欺骗；使用时尊重真实疾病，避免把诊断名当万能反转。

### 5. 语言与叙述

- 词义与语用：多义词、断句、同音、量词、否定范围、字面/比喻或专业口径。
- 指代与省略：主语、“他/她/它/他们”、关系对象或被省略的共有前提。
- 视角与焦点：第一/第三人称、观察者位置、所知范围或自由间接引语。
- 不可靠叙述：说谎、误认、受限认知、转述污染；可靠性必须能由题内异常识别。
- 载体与编辑：日记、遗书、录音、字幕、聊天记录、监控、新闻、剧本或剪辑顺序。
- 元叙事与第四面墙：玩家、主持人、作者、读者、角色和界面的层级互换。
- 主持人有限视角：主持人是角色、记录系统或非全知观察者；必须预先声明回答口径，不能借此临场逃避矛盾。

### 6. 信息、证据与知识差

- 信息不对称：不同人物、玩家与主持人掌握不同事实。
- 证词与来源：目击、传闻、机器输出、权威判断的来源可靠性不同。
- 伪造与污染：伪证、调包、深度伪造、日志篡改、样本污染或链路攻击。
- 缺席证据：本应出现却没有出现的声音、尸体、影子、记录或反应。
- 统计与选择偏差：幸存者偏差、取样偏差、基率忽视、相关误作因果。
- 数字取证：时间戳、账号、权限、缓存、自动化记录、传感器与网络延迟。

### 7. 因果、行动与动机

- 因果倒置：先看到结果而误判原因，或把共同原因当直接因果。
- 闭环与自证：行动因预言、警告或救援而发生，并反过来制造最初条件。
- 目的/结果错位：救援造成伤害、谋杀实现保护、仪式只是掩护或失败本身是目标。
- 多段机制链：每一环单独普通，组合后造成异常结果。
- 共谋与博弈：多方目标、囚徒困境、信号、诈唬、替罪与互相利用。
- 道德或制度因果：法律、组织流程、禁忌、激励结构迫使人物采取反常行动。

### 8. 规则与系统

- 规则怪谈：规则同时包含保护、误导、敌我识别与漏洞；规则之间应可交叉验证。
- 仪式、契约与禁忌：宗教、民俗或神话规则的触发、代价与解释权限。
- 游戏与竞赛：胜负条件、隐藏阵营、回合、资源、淘汰与角色能力。
- 制度与程序：医院、司法、公司、学校、平台审核或自动决策流程。
- 算法与协议：权限、状态机、条件分支、递归、复制、漏洞与对抗样本。

### 9. 世界层级与本体

- 梦境/现实、故事/现实、游戏/现实、虚拟/物理世界的层级错认。
- 模拟、AI、意识上传、数字永生、机器人或赛博义体改变“人”的边界。
- 低维/高维、投影、观察维度或不可见自由度改变空间与因果理解。
- 平行宇宙、世界线、轮回、转生、身穿、魂穿、召唤或附身。
- 创作者/角色、玩家/主持人、训练数据/生成内容之间的本体关系。

世界层级只有在层与层之间存在可观察接口时才可推理，例如记忆残留、日志差异、物理投影、权限错误或跨层因果。

## 三、设定实现层：用什么外壳承载机制

这些标签回答“故事如何实现”，不自动构成诡计：

- 犯罪与法证：凶杀、绑架、失踪、密室、伪证、毒物、尸体处理。
- 悬疑、恐怖、惊悚：威胁来源、节奏与情绪，不等于超自然真实存在。
- 科幻与未来：时间技术、克隆、AI、太空、末日、生物工程。
- 赛博朋克：义体、意识商品化、公司统治、监控社会、数字身份。
- 灵异与怪谈：鬼怪、诅咒、都市传说、异常空间、收容物。
- 宗教、信仰与神话：神学体系、教派、献祭、神谕、创世与末世。
- 民俗与地方传说：婚丧、节庆、禁忌、祖灵、地方神与口述传统。
- 历史、战争、灾难、医疗、家庭、校园、职场、网络、娱乐产业等现实场域。

若答案依赖冷门背景，在汤面或可获得提示中补充最低必要知识；玩家的任务应是推理其作用，不是猜作者查过哪本资料。

## 四、结构与玩法形式

- 结构：单反转、双层反转、嵌套故事、多时间线、多视角、双解、循环、因果闭环、角色互换、非线性拼图。
- 篇幅：一句微型汤、标准汤、长故事汤、多阶段解锁汤。
- 交互：限次问答、计分点、角色扮演、隐藏阵营、道具/文档、分支选择、主持机制、合作或对抗。
- 叙事：规则怪谈、档案体、聊天记录体、审讯体、模拟系统、元叙事。

“主持人并非上帝视角”属于主持机制。出题时固定三件事：主持人是谁、他能访问什么、回答“是/否”的参照世界是哪一个。

## 五、主题、情绪与审美

- 主题：亲情、爱情、友情、牺牲、救赎、复仇、正义、信任、创伤、成长、死亡、人性、身份认同、自由意志、命运、科技伦理、信仰冲突、社会制度。
- 情绪回收：震惊、悲伤、温暖、恐惧、荒诞、讽刺、释然、悔恨、庄严。
- 审美风格：本格冷峻、哥特、克苏鲁式宇宙恐怖、黑色幽默、民俗恐怖、赛博朋克、童话反转、日常异化。

主题负责“为什么值得讲”，核心机制负责“为什么能推出来”。两者最好在结局同一点回收，但不能互相替代。

## 六、组合纪律

设计复杂汤时填写：

```text
现实性：
主机制（唯一）：
辅助机制（0—1 个）及不可替代功能：
设定实现层：
结构与玩法：
玩家最初的错误模型：
迫使模型重构的线索：
每条特殊规则的触发 / 范围 / 边界 / 代价 / 可观察后果：
题外背景的最低必要补充：
主题与情绪回收：
```

每增加一个机制或世界规则，至少满足一项：解释既有矛盾、制造可观察线索、排除替代解、驱动人物必然行动、完成主题回收。只增加名词或氛围的元素应删除或降为背景。

## 七、分类学习法

分析现有作品时，不复制表面人物与场景，提取以下可迁移结构：

1. **错误模型**：玩家因哪句话、常识或叙事惯例作出什么默认假设。
2. **重构机关**：哪条线索迫使玩家改变时间、空间、身份、视角或规则模型。
3. **线索功能**：每条线索是建立误导、确认机制、限定边界还是排除替代解。
4. **规则成本**：解答引入了多少题面之外的新设定；关键结论是否依赖临时补丁。
5. **问答路径**：玩家能否通过若干自然问题逐层接近真相，而不是穷举冷知识。
6. **情绪回收**：反转是否重新解释人物行为、台词与主题，而非只揭露名词。
7. **可迁移技法**：只记录抽象机制和设计原则；换皮仍等同原作的，不算原创。

标注一题时至少产出：主机制、辅助机制、现实性、实现层、结构形式、错误模型、决定性线索、最佳学习领域与风险。标签不能代替事实链和公平性审计。
